FLAPPYBIRD.IO FLIGHTDECK

1. Open https://flappybird.io/ in Chrome.
2. Press F12.
3. Open Sources > Snippets.
4. Create a new snippet.
5. Open flappybird-io-cheat.js from this ZIP, copy everything, and paste it into the snippet.
6. Press Ctrl+S, then Ctrl+Enter to run it.

the panel to increase speed. The steering decision runs before every native
physics step, so accelerated play uses the same pilot logic as normal speed.

Custom speed:
- Type any value from 1x to 250x in the speed box and press Enter.

- Use the minus/plus buttons for precise 0.25x, 1x, or 5x nudges.

Assisted play, collision recovery, and accelerated simulation remain local and
unranked so competitive leaderboard scores stay legitimate.

Hotkeys:
